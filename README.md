# Hotel Green Plaza — Official Website

Static website for **Hotel Green Plaza & Restaurant**, Bhilwara, Rajasthan.

## Project Structure

```
Hotel Green Plaza/
├── _build/                    # Build & audit tools (not deployed)
│   ├── build.py               # Static site generator — edit content here
│   ├── audit.py               # Quality checker (links, SEO, accessibility)
│   ├── fetch_placeholder_photos.py
│   └── make_placeholders.py
│
├── assets/
│   ├── css/style.css          # Single consolidated stylesheet
│   ├── js/main.js             # Vanilla JS (nav, gallery, menu filter, carousel)
│   └── img/
│       ├── hero/              # Full-bleed hero & banner images
│       ├── gallery/           # Gallery page images
│       ├── general/           # Section content images
│       ├── rooms/             # Room card images
│       └── logo/              # Logo, favicon, PWA icons
│
├── about-us/index.html        # Generated — do not hand-edit
├── accommodation/index.html
├── banquets/index.html
├── contact/index.html
├── gallery/index.html
├── restaurant/index.html
├── services/index.html
├── 404.html
├── index.html
│
├── enquiry.php                # Server-side contact form handler
├── sitemap.xml                # Auto-generated by build.py
└── robots.txt                 # Auto-generated by build.py
```

## How to Build

```bash
python _build/build.py    # Regenerates all HTML, sitemap.xml, robots.txt
python _build/audit.py    # Must print "No problems found." before committing
```

All site content lives in `_build/build.py` — hotel details, menu items, room
descriptions, amenities, contact info, branch data. Edit there and rebuild.
Never hand-edit the generated HTML files directly.

## Tech Stack

- Pure static HTML/CSS/JS — no framework, no build pipeline, no dependencies
- Single stylesheet with CSS custom property design tokens
- Inline SVG sprite for all icons
- Asset cache-busting via MD5 content hash (`style.css?v=xxxx`)

## Before Going Live

Replace every `[VERIFY: ...]` placeholder in the generated HTML (run `python _build/audit.py` to list them):

- Real hotel photography (39 placeholder images)
- Confirmed room names, pricing, and availability
- Restaurant timings
- Geo coordinates for the map
- Neemuch / Jaora branch details
- Domain (www vs non-www + HTTPS)
- `$RECIPIENT` email in `enquiry.php`
